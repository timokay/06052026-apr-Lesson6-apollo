Подготовь CSV-файл со следующей структурой. Можно в одном файле или раздельно.

  Файл 1: companies.csv

  inn,name,okved_main,region,employee_count,revenue_range,address,director
  7707083893,Сбербанк,64.19,Москва,286000,10B+,"ул. Вавилова, 19, Москва",Греф Герман Оскарович

  ┌────────────────┬───────────────────────────────────────────────────────────────────┬─────────────────┐
  │    Колонка     │                              Формат                               │  Обязательная   │
  ├────────────────┼───────────────────────────────────────────────────────────────────┼─────────────────┤
  │ inn            │ строка, 10-12 цифр                                                │ да (уникальный) │
  ├────────────────┼───────────────────────────────────────────────────────────────────┼─────────────────┤
  │ name           │ строка                                                            │ да              │
  ├────────────────┼───────────────────────────────────────────────────────────────────┼─────────────────┤
  │ okved_main     │ строка, код ОКВЭД (напр. 62.01)                                   │ нет             │
  ├────────────────┼───────────────────────────────────────────────────────────────────┼─────────────────┤
  │ region         │ строка (напр. Москва, Санкт-Петербург)                            │ нет             │
  ├────────────────┼───────────────────────────────────────────────────────────────────┼─────────────────┤
  │ employee_count │ число                                                             │ нет             │
  ├────────────────┼───────────────────────────────────────────────────────────────────┼─────────────────┤
  │ revenue_range  │ строка: <10M, 10M-50M, 50M-100M, 100M-500M, 500M-1B, 1B-10B, 10B+ │ нет             │
  ├────────────────┼───────────────────────────────────────────────────────────────────┼─────────────────┤
  │ address        │ строка                                                            │ нет             │
  ├────────────────┼───────────────────────────────────────────────────────────────────┼─────────────────┤
  │ director       │ строка, ФИО                                                       │ нет             │
  └────────────────┴───────────────────────────────────────────────────────────────────┴─────────────────┘

  company_inn,name,title,email,phone,telegram
  7707083893,Алексей Смирнов,VP of Digital,a.smirnov@sberbank.ru,+7-495-500-0001,@asmirnov

 Файл 2: contacts.csv

  company_inn,name,title,email,phone,telegram
  7707083893,Алексей Смирнов,VP of Digital,a.smirnov@sberbank.ru,+7-495-500-0001,@asmirnov

  ┌─────────────┬────────────────────────────────────────────┬──────────────┐
  │   Колонка   │                   Формат                   │ Обязательная │
  ├─────────────┼────────────────────────────────────────────┼──────────────┤
  │ company_inn │ ИНН компании из первого файла (для связки) │ да           │
  ├─────────────┼────────────────────────────────────────────┼──────────────┤
  │ name        │ ФИО контакта                               │ да           │
  ├─────────────┼────────────────────────────────────────────┼──────────────┤
  │ title       │ должность                                  │ нет          │
  ├─────────────┼────────────────────────────────────────────┼──────────────┤
  │ email       │ email                                      │ нет          │
  ├─────────────┼────────────────────────────────────────────┼──────────────┤
  │ phone       │ телефон                                    │ нет          │
  ├─────────────┼────────────────────────────────────────────┼──────────────┤
  │ telegram    │ @username                                  │ нет          │
  └─────────────┴────────────────────────────────────────────┴──────────────┘

  Формат

  - CSV с заголовками, разделитель ,, кодировка UTF-8
  - Значения с запятыми оберни в кавычки "..."
  - Пустые поля оставь пустыми (не пиши NULL)
